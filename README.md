# BO2 Deathmachine Power Up Mod

BO2 Deathmachine Power Up Mod!

*Note: This was made for people to add to their mods, but I have still given out a mod if you'd like to try it out*

## **How to install!**

* Download and install the **CLL (Cod Lan Launcher)**: [github.com/MestreTM/CLL-Cod-Lan-Launcher](https://github.com/MestreTM/CLL-Cod-Lan-Launcher) (see the Releases page)

* Install by home page

* You're done! You may load up T6 and enjoy!
